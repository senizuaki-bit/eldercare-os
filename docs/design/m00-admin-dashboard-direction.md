# M00 admin dashboard visual direction

## Selection

The selected design is `m00-admin-dashboard-direction.png`, the first of three independently generated Product Design directions. It was selected because it most clearly places the four critical queues ahead of analytics while retaining a compact, auditable enterprise layout.

## Generation

- Mode: built-in ImageGen
- Use case: `ui-mockup`
- Target: 1440 × 1024 desktop administration screen
- Date anchor: 2026-07-11
- Source references: admin reference images under `docs/references/`, used as inspiration only

## Prompt

```text
Design one focused Chinese eldercare operations risk-triage dashboard for a facility director or nursing supervisor. Calm, editorial, operational and highly readable. The hero use case is immediately understanding and acting on four queues: unacknowledged emergencies, AI drafts awaiting human review, overdue work orders and critical devices offline.

Use a narrow deep-teal left navigation, compact white top bar, breadcrumb, page title and a full-width priority ledger before restrained operational metrics. Use a cool gray-white base, white surfaces, deep teal primary, stable blue secondary, amber and red only for risk, and dark blue-gray text. Status must use icon, label and explanation. Do not copy any exact composition, brand, logo, names, avatars, photos, watermarks, proprietary text or icon combinations from the references. No real personal data, diagnosis language, decorative donut chart, glossy gradients or clipped content.
```

The implementation may correct generated copy and improve accessibility, but should preserve the selected hierarchy, density, proportions, palette and interaction emphasis.
